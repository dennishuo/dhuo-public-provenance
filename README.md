# dhuo-public-provenance — working notes (reviewable beta)

Promoted subsets of private working provenance: rough polish, honest registers — but
citation quality, evidence grades, correction state, and leak review are floors, not
aspirations. Promotion-driven and append-only: entries arrive via a typed export pipeline
carrying an opaque promotion receipt and a fresh public identifier; corrections arrive as
new versions that supersede, never as history rewrites.

This is a working-notes repository, not a supported product: no issues triage, no
compatibility promises, content may be superseded at any time.
